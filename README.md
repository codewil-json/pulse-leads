# Pulse Leads

Sistema moderno de gestão de leads desenvolvido com Vue.js, Node.js e MongoDB.

## 🚀 Sobre o projeto

O Pulse Leads é um CRM leve e intuitivo criado para facilitar o gerenciamento de leads, acompanhamento de negociações e organização comercial.

O objetivo do sistema é oferecer uma experiência rápida, limpa e eficiente para equipes comerciais e profissionais que precisam organizar contatos e oportunidades de venda.

---

## ✨ Funcionalidades

* 🔐 Autenticação de usuários
* 📋 Cadastro de leads
* ✏️ Edição de leads
* 🗑️ Remoção de leads
* 🔎 Busca e filtros
* 📊 Dashboard
* 📌 Controle de status
* 📝 Observações e anotações
* 📱 Interface moderna e responsiva

## ⚙️ Instalação

### Clone o projeto

```bash
git clone git@github.com:codewil-json/pulse-leads.git
```

---

## 📦 Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## ⚙️ Backend

```bash
cd backend
npm install
npm run dev
```

---

## 🔑 Variáveis de ambiente

Crie um arquivo `.env` dentro da pasta `backend`.

```env
PORT=3000

MONGO_URI=mongodb://localhost:27017/pulseleads

JWT_SECRET=suachavesecreta
```
